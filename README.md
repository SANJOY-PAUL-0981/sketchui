## Tech Stack
- [Rough.js](https://roughjs.com/)
- [NextJS](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [TailwindCSS](http://tailwindcss.com/)
- [bun](https://bun.com/)

## Local setup

### Requirements

- Node.js 20+
- bun

### Install

```bash
git clone https://github.com/SANJOY-PAUL-0981/sketchui.git
cd sketchui
bun install
```

### Run

```bash
bun dev
```
